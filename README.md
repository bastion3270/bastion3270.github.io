# bastion3270.github.io

Source of the website <https://bastion3270.github.io>, the home page of
[bastion3270](https://github.com/tom-danek/bastion3270) — an open-source TN3270 web gateway and
desktop 3270 client written in Rust.

The site is plain HTML and CSS without a build step, served by GitHub Pages from the `main`
branch. Open `index.html` in a browser to preview it.
